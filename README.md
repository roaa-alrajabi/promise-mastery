# promise-mastery


what is the Promises?
The promises is  object instance from class Promises, that have 3 status Pending, Fulfilled, Rejected.

Why we need the Promises ? 
We need Promises to manage asynchronous operations, avoid callback hell, and make code more readable and maintainable.


Note: You can add a function with .then() even while the Promises is still running. That function will automatically execute once the Promises resolves.
